# PageLens 产品功能地图

按用户看到的名称定位功能。入口 ID 来自[侧栏页面](../extension/sidepanel/index.html)。同一项功能可以跨侧栏、后台和本机进程，最后一列给出最先值得运行的验证。新增入口、迁移实现或修改用户约定时，在同一个改动里更新对应行。

### Temu 选品与富图

市场结果和本地目录使用双列图片卡片。富图按所选参考照片迁移配色、图案和布局，核对时同时比较原图、成图和参考图。极鲸云图搜将站点与分页字段一起放入 multipart 并签名。

从「工作流 → Temu → 选品与富图」进入。高级配置可启用极鲸云。市场选品限定已核对的欧盟站点，展示周销量、增长率、价格及详情返回的历史。只在用户发起查询时调用商品接口，结果缓存 12 小时，每种付费接口在 12 小时内最多发起两次。目录富图可加载商品清单或散图，选择已有模型逐件或批量编辑印花。选品候选可设为独立的印花参考，底图确定服装结构，市场参考则提供图案布局、密度和配色。支持标准和进阶裂变、并排放大、AI 核对和人工确认。商品导出使用现有上架目录格式，保留已获取的 SKU、属性、尺码和来源数据。
